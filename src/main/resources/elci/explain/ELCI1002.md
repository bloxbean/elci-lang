# ELCI1002: Malformed or unsupported syntax

The parser found something it cannot read at this point: a missing or extra token, or a form
Elci does not support. The message says what it expected, or what to write instead.

Common causes:

- A refutable pattern, such as `(x :: _)`, as a function parameter.
- A missing `else`, `then`, `of`, `->` or closing bracket.
- Chained comparisons such as `1 < 2 < 3`, or `<|` and `|>` mixed without parentheses.
- An extensible record type such as `{ r | name : String }`.
- A tuple with more than three elements.

## Example

```elm
first : List Int -> Int
first (x :: _) =
    x


main : Int
main =
    first [ 1, 2 ]
```

`elci check` reports:

```text
src/Main.elm:5:8: ELCI1002: Function parameters require irrefutable patterns; use case for refutable matching

5| first (x :: _) =
          ^
```

## Fix

A function parameter must match every value of its type. Match with `case`, and handle every
shape:

```elm
first : List Int -> Int
first values =
    case values of
        x :: _ ->
            x

        [] ->
            0


main : Int
main =
    first [ 1, 2 ]
```
