# ELCI2101: Unknown module or import

An import names a module or an exposed name that doesn't exist.

Common causes:

- A misspelt module name. The hint suggests a close one.
- A project module whose file is missing from the source directories.
- A Java library module with no `[java-modules]` mapping.
- An unknown ledger type in `import Julc.Ledger exposing (...)`.
- A source module that imports the test library (`Expect`, `Scenario` or `Property`), which only
  test modules may import.

## Example

```elm
import Julc.Ledgr exposing (PubKeyHash)


main : Int
main =
    0
```

`elci check` reports:

```text
src/Main.elm:3:1: ELCI2101: Missing source module: Julc.Ledgr; add Julc/Ledgr.elm under a source directory, or map a Java library to it under [java-modules]

3| import Julc.Ledgr exposing (PubKeyHash)
   ^^^^^^
Hint: did you mean `Julc.Ledger`?
```

## Fix

Correct the name, add the module's file under a source directory, or map the Java library under
`[java-modules]` in `elci.toml`:

```elm
import Julc.Ledger exposing (PubKeyHash)


main : Int
main =
    0
```
