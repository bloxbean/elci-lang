# ELCI2006: Duplicate binder or unreachable pattern

A pattern is redundant or ambiguous.

Common causes:

- A `case` branch that can never match, because the branches before it cover every value it
  would match.
- A pattern that binds the same name twice, such as `( x, x )`.

## Example

```elm
describe : Maybe Int -> Int
describe value =
    case value of
        Just n ->
            n

        Nothing ->
            0

        Just _ ->
            1


main : Int
main =
    describe Nothing
```

`elci check` reports:

```text
src/Main.elm:13:9: ELCI2006: Unreachable pattern

13|         Just _ ->
            ^^^^
```

## Fix

Remove the branch that can never match, or move a more specific branch above the one that
covers it:

```elm
describe : Maybe Int -> Int
describe value =
    case value of
        Just n ->
            n

        Nothing ->
            0


main : Int
main =
    describe Nothing
```

For a duplicate binder, give each variable its own name, and compare them with `==` if they
must be equal.
