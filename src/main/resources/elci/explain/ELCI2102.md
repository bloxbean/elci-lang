# ELCI2102: Ambiguous name

Two imports expose different things under one name, and the code uses it unqualified. One of
them may be a default import such as `Basics`. An ambiguous type name is reported at the
declaration whose annotation uses it.

## Example

```elm
module Utils exposing (max)


max : Int -> Int -> Int
max a b =
    if a > b then
        a

    else
        b
```

```elm
module Main exposing (main)

import Utils exposing (..)


main : Int
main =
    max 1 2
```

`elci check` reports:

```text
src/Main.elm:8:5: ELCI2102: max is ambiguous: it could be Basics.max or Utils.max. Write the one you mean, like Basics.max, or stop exposing the other

8|     max 1 2
       ^^^
```

## Fix

Write the one you mean with its module, or stop exposing the other:

```elm
module Main exposing (main)

import Utils


main : Int
main =
    Utils.max 1 2
```

Listing the name in the import, as in `import Utils exposing (max)`, also settles a clash with a
default import.
