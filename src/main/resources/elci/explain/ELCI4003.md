# ELCI4003: Backend capability missing

The Julc backend in use lacks a capability the program needs. Elci checks the backend's
capabilities before generating code. This happens only when Elci runs with a Julc build other
than the one it was released with.

## Fix

Run Elci with the Julc version it was built for: `elci --version` shows both. If they match,
please report the program with the full message.
