# ELCI2012: Invalid type

A type written in a signature or declaration is not valid.

Common causes:

- A type name that is not declared or imported in the module, often a misspelling. The hint
  suggests a close name.
- A type given the wrong number of arguments, such as `List Int Int`.
- Type aliases that refer to each other in a loop.
- `Tuple Int Int` or `Unit` as a type name. Write `( Int, Int )` and `()`.

## Example

```elm
main : Strin
main =
    "x"
```

`elci check` reports:

```text
src/Main.elm:4:1: ELCI2012: Type is not declared or imported in this module: Strin

4| main : Strin
   ^^^^
Hint: did you mean `String`?
```

## Fix

Correct the spelling, or declare or import the type:

```elm
main : String
main =
    "x"
```
