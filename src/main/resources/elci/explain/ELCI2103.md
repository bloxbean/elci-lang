# ELCI2103: Not exposed

The function that `elci.toml` names as the entrypoint or a validator handler is defined, but its
module doesn't expose it. Only exposed functions can be compiled as scripts.

## Example

```elm
module Main exposing (helper)


helper : Int
helper =
    1


main : Int
main =
    helper
```

`elci check` reports:

```text
src/Main.elm:9:1: ELCI2103: Entrypoint Main.main must be exposed by its module

9| main : Int
   ^^^^
```

## Fix

Add the function to the module's `exposing` list:

```elm
module Main exposing (helper, main)


helper : Int
helper =
    1


main : Int
main =
    helper
```
