# ELCI3002: Specialization limit

Elci compiles each generic function once for each type it is used at. A program may create at
most 256 of these specializations. A program reaches the limit through polymorphic recursion:
a generic function that calls itself at a larger type each time, such as `( a, a )` for `a`.
Inference rejects most of these as ELCI2002.

## Fix

Make the recursive function monomorphic: have it call itself at the type it was given, and
build the larger values in a separate function or in the data it recurses over.
