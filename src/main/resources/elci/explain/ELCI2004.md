# ELCI2004: Missing signature

Every top-level declaration needs a type signature. The signature documents the declaration,
states its boundary types, and lets Elci report a mistake where it is made. Local definitions in
a `let` do not need one.

## Example

```elm
double x =
    x * 2


main : Int
main =
    double 4
```

`elci check` reports:

```text
src/Main.elm:4:1: ELCI2004: Top-level declarations require a type signature

4| double x =
   ^^^^^^
```

## Fix

Write the signature directly above the definition:

```elm
double : Int -> Int
double x =
    x * 2


main : Int
main =
    double 4
```
