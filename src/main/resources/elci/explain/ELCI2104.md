# ELCI2104: Module or qualified name error

A qualified name, an import or a module declaration doesn't fit the modules the project has.

Common causes:

- A qualified name whose module is not imported, doesn't exist, or doesn't have the name, such
  as `List.lenght`. For an Elm function that Elci doesn't provide, the message says what to use
  instead. The hint suggests close names.
- A module imported with an alias but used by its full name, or the reverse.
- A core module that isn't imported by default, such as `Bytes`, `Dict`, `Map`, `Array` or
  `Julc.Data`, used without its import.
- An import that exposes a name the module doesn't have.
- A `module` line that doesn't match the file's path, or an import cycle.
- A module or alias named after a core module, such as `String` or `Tx`.

## Example

```elm
main : Int
main =
    Lsit.length [ 1, 2 ]
```

`elci check` reports:

```text
src/Main.elm:6:5: ELCI2104: No module Lsit is imported, and none has that name

6|     Lsit.length [ 1, 2 ]
       ^^^^^^^^^^^
Hint: did you mean `List.length`?
```

## Fix

Correct the name, or import the module it belongs to:

```elm
main : Int
main =
    List.length [ 1, 2 ]
```
