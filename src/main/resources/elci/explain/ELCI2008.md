# ELCI2008: Eager value cycle

Values that are not functions are computed eagerly, when they are defined. Two values that
depend on each other in a loop can never be computed. Only functions can be recursive.

## Example

```elm
main : Int
main =
    let
        a =
            b + 1

        b =
            a + 1
    in
    a
```

`elci check` reports:

```text
src/Main.elm:7:9: ELCI2008: Cyclic eager values are unsupported; recursion requires functions

7|         a =
           ^
```

## Fix

Break the cycle so that each value depends only on values defined without it:

```elm
main : Int
main =
    let
        a =
            1

        b =
            a + 1
    in
    b
```

When the repetition is intended, write it as a recursive function with a base case.
