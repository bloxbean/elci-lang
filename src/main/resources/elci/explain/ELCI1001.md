# ELCI1001: Invalid character or literal

The source contains a character or literal that Elci does not accept. Elci reads Elm source,
but a few things Elm allows have no meaning on chain.

Common causes:

- A number with a fractional part, such as `1.5`. Elci has one number type, `Int`.
- A tab. Indent with spaces.
- A character outside Elm syntax, such as `%`, or a `'c'` character literal.
- An unknown string escape such as `\q`, or a string left open at the end of its line.

## Example

```elm
main : Int
main =
    1.5
```

`elci check` reports:

```text
src/Main.elm:6:6: ELCI1001: Float is unsupported; represent fractional amounts using an explicit integer scale

6|     1.5
        ^
```

## Fix

Use integers with an explicit scale: lovelace instead of ada, or basis points instead of
percentages.

```elm
main : Int
main =
    1500000
```
