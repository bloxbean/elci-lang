# ELCI2010: Unknown record field

A field is read or updated that the record doesn't have. The message lists the fields it has,
and a hint suggests a close name.

It is also reported when Elci cannot tell which record type a field access belongs to. Add a
signature with the record type.

## Example

```elm
main : Int
main =
    let
        order =
            { amount = 5 }
    in
    order.price
```

`elci check` reports:

```text
src/Main.elm:10:10: ELCI2010: Missing field 'price'; available fields: [amount]

10|     order.price
             ^^^^^^
```

## Fix

Use one of the listed fields, or add the field to the record:

```elm
main : Int
main =
    let
        order =
            { amount = 5 }
    in
    order.amount
```
