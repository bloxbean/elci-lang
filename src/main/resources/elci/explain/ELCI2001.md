# ELCI2001: Invalid expression or pattern

An expression or pattern has a form that cannot work in Elci, although it parses.

Common causes:

- Division with `/`. Elci has no `Float`, so it uses `//` for the integer quotient.
- A constructor pattern with too many or too few arguments, such as `Just x y`.
- A misspelt constructor in a pattern.
- A record pattern such as `{ index }` on a ledger record, which a pattern cannot take apart.

## Example

```elm
main : Int
main =
    7 / 2
```

`elci check` reports:

```text
src/Main.elm:6:7: ELCI2001: Float division is unsupported; use // for integer quotient

6|     7 / 2
         ^
```

## Fix

Use `//`, together with `modBy` or `remainderBy` when you need the rest:

```elm
main : Int
main =
    7 // 2
```

For a pattern, give the constructor exactly its arguments, and read a ledger record's fields
with `.field` instead of a record pattern.
