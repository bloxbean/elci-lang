# ELCI2011: Duplicate type or constructor

A type or constructor name is declared twice, or takes a name that belongs to a built-in type.

Common causes:

- Two custom types in one module with a constructor of the same name.
- A constructor named `Just`, `Nothing`, `True` or `False`.
- A type named after a built-in type, such as `Int`, `Bool`, `String`, `Bytes`, `Data`, `List`,
  `Maybe`, `Map` or `Array`.

## Example

```elm
type Action
    = Buy Int
    | Sell Int


type Request
    = Buy
    | Cancel


main : Int
main =
    0
```

`elci check` reports:

```text
src/Main.elm:9:6: ELCI2011: Duplicate constructor Buy: the type Action has one too

9| type Request
        ^^^^^^^
```

## Fix

Give each constructor a name of its own:

```elm
type Action
    = Buy Int
    | Sell Int


type Request
    = Order
    | Cancel


main : Int
main =
    0
```
