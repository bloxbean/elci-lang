# ELCI2009: Type is not concrete

An entrypoint, a validator handler or a property test has a type with a type variable in it.
Its values cross into or out of the chain, or are generated for a test. Elci must know their
exact type to encode them.

## Example

```elm
main : List a
main =
    []
```

`elci check` reports:

```text
src/Main.elm:4:1: ELCI2009: Entrypoints require concrete types

4| main : List a
   ^^^^
```

## Fix

Replace each type variable with a concrete type:

```elm
main : List Int
main =
    []
```
