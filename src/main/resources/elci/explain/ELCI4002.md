# ELCI4002: Backend rejected the generated code

Julc's PIR verifier rejected the code Elci generated for the program. The error is reported at
the Elci declaration involved, and the message keeps Julc's own `JULC00xx` code.

This is a compiler problem, not a mistake in your code. Please report it with the program that
triggers it.

## Fix

Report the program with the full message. Include `elci --version`.
